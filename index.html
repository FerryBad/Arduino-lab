Fun little games

Quick games you can actually build with common starter-kit parts. Pick one, wire it up, upload the sketch, and play!

⚡ GAME 01

Reaction Rush

Wait for the LED, then hit the button as fast as possible. Your reaction time appears in the Serial Monitor.

🧰 Parts

Arduino Uno, LED, 220Ω resistor, pushbutton

🔌 Wiring

  • LED → D9 through 220Ω → GND
  • Button → D2 and GND

💻 Arduino IDE code

🎯 GAME 02

Lucky Target

Three LEDs flash in a pattern. Press the button when the target LED is on to score points.

🧰 Parts

3 LEDs, 3×220Ω resistors, pushbutton

🔌 Wiring

  • LEDs → D8, D9, D10 through 220Ω resistors
  • Button → D2 and GND

💻 Arduino IDE code

🧠 GAME 03

Simon Says Mini

Watch the LEDs, then repeat the sequence with buttons. Each round gets longer!

🧰 Parts

3 LEDs, 3×220Ω resistors, 3 pushbuttons

🔌 Wiring

  • LEDs → D8, D9, D10 through 220Ω resistors
  • Buttons → D2, D3, D4 and GND

💻 Arduino IDE code

🎲 GAME 04

Digital Dice

Press the button and the LEDs display a random number from 1 to 6 like a tiny electronic dice.

🧰 Parts

6 LEDs, 6×220Ω resistors, pushbutton

🔌 Wiring

  • LEDs → D3–D8 through 220Ω resistors
  • Button → D2 and GND

💻 Arduino IDE code
